# 💖 Kabi & Aklu's Romantic 3D Website

Dedicated romantic web application crafted for **Akalya (Aklu)** with love from **Kabil (Kabi)**.

## ✨ Features Included:
1. **Three.js 3D Floating Particles & Stars Galaxy** that react in real-time to mouse and touch movement.
2. **Interactive 3D Love Envelope & Letter** with realistic open/close animation.
3. **Interactive 3D Carousel Cylinder** populated with hand-picked dreamy online aesthetic photography, draggable and swipeable.
4. **3D Flip Cards (Secrets)** that reveal sweet personalized messages.
5. **Playful "Will You Go Out With Me?" Section** where the "No" button hilariously runs away so she can only say **YES!**.
6. **Background Romantic Piano Audio Player** with spinning vinyl pill controller.
7. **Canvas Confetti & Floating Heart Bursts** on every screen tap.

## 🚀 How to Host on GitHub Pages (Step-by-Step)

1. Open [GitHub](https://github.com/) and create a new repository (e.g., `for-aklu` or `kabi-loves-aklu`).
2. Make sure the repository is set to **Public**.
3. Upload all 3 files (`index.html`, `style.css`, and `script.js`) into the repository.
4. Go to **Settings** > **Pages** (on the left menu).
5. Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
6. In about 60 seconds, GitHub will give you a live link like:
   `https://<your-username>.github.io/<repo-name>/`
7. Share that link with Aklu and watch her smile! 🥰
